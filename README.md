# داري (DARI) - منصة العقارات الذكية في الجزائر 🇩🇿

منصة عصرية ومبتكرة تهدف لتسهيل عملية كراء العقارات في الجزائر، مع دمج تقنيات الذكاء الاصطناعي لتقديم تجربة مستخدم استثنائية.

## 🌟 المميزات الرئيسية
- **نظام بحث متطور**: تصفية انسيابية حسب الولاية، السعر، عدد الغرف، والطابق.
- **توصيات الذكاء الاصطناعي**: نظام اقتراحات ذكي مبني على تفضيلات المستخدم (Genkit).
- **التوثيق والمصداقية**: شارات "عقار موثق" للعقارات التي تملك عقد ملكية.
- **حاسبة التكاليف**: حساب فوري لمبالغ التسبيق وعمولات الوساطة.
- **نظام التنبيهات**: إرسال إشعارات فورية (SMS/Email) عند طلب الحجز.
- **لوحة تحكم المعلن**: سهولة إضافة العقارات مع نظام رفع الصور ووصف محسّن بالذكاء الاصطناعي.

## 🛠 التقنيات المستخدمة
- **Framework**: [Next.js 15+](https://nextjs.org/)
- **Frontend**: React, Tailwind CSS, Shadcn UI
- **Backend**: [Firebase](https://firebase.google.com/) (Auth, Firestore)
- **AI Engine**: [Google Genkit](https://github.com/firebase/genkit)
- **Icons**: Lucide React

## 🚀 التشغيل المحلي
1. قم بتحميل المشروع:
   ```bash
   git clone [رابط-المستودع]
   ```
2. قم بتثبيت المكتبات:
   ```bash
   npm install
   ```
3. قم بإعداد متغيرات البيئة في ملف `.env.local`:
   ```env
   NEXT_PUBLIC_FIREBASE_API_KEY=your_key
   NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_id
   # ... بقية إعدادات فايربيس وجينكيت
   ```
4. ابدأ التشغيل:
   ```bash
   npm run dev
   ```

## 📜 شروط الخدمة والخصوصية
التطبيق يشجع على الشفافية (إظهار عيوب العقار) والالتزام بالأخلاق المهنية في التعاملات العقارية.
