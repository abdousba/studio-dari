# **App Name**: Dzayer Cribs

## Core Features:

- Property Listing: Allow users to list properties for rent with details such as location, price, and amenities.
- Image Compression: Automatically compress uploaded images to an optimal size for fast loading without losing quality.
- Search and Filtering: Enable users to search and filter properties based on location, price range, number of rooms, and other criteria.
- Map Integration: Integrate a map to display the location of each property and allow users to explore nearby amenities.
- AI-Powered Property Recommendations: Use an AI tool to suggest properties based on user preferences and search history, enhancing the discovery process.
- User Authentication: Allow users to create accounts, save favorite properties, and manage their listings.
- Contact the lister: Allow potential renters to directly contact the poster through the application.

## Style Guidelines:

- Primary color: Soft coral (#F08080), evoking warmth and comfort in a contemporary way.
- Background color: Pale peach (#FAF0E6), for a gentle, inviting base. This provides a high-key, bright background.
- Accent color: Muted lavender (#E6E6FA) to add a touch of elegance and calm.
- Headline font: 'Belleza' sans-serif for a design-forward appearance. Body font: 'Alegreya' serif.
- Use simple, modern icons that are easy to understand and align with the pastel color scheme.
- Design a clean, intuitive layout with clear sections and easy navigation for property listings and search filters.
- Implement subtle transitions and animations to enhance user engagement and provide a smooth browsing experience.
